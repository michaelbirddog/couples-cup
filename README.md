# Couples Cup

Interactive tournament board for **5 couples** and **2 games**.

Every couple plays every other couple once in each game (20 matches). Optional 1st vs 2nd finals after the round robin.

## Open the board

- GitHub file: https://github.com/michaelbirddog/couples-cup
- Live preview: https://raw.githack.com/michaelbirddog/couples-cup/main/index.html
- Download `index.html` and open it on any phone or laptop.

## How to share scores

1. Enter couple names and game names.
2. Tap matches to enter scores.
3. Tap **Copy link** and send that URL. Names and scores live in the link hash, so the group sees the same board.
